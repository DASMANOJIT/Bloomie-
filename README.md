# Bloomie – The Crochet Store

A polished single-page showcase website for a handmade crochet business. Built with Next.js App Router, TypeScript, Tailwind CSS and Lucide React.

## Setup

1. Install dependencies with `pnpm install`.
2. Copy `.env.example` to `.env.local`.
3. Replace the example WhatsApp number with the full international number (digits only) and set the Instagram profile URL.
4. Run `pnpm dev` and open the local URL.

## Brand assets

Replace `public/images/bloomie-logo-v2.png` with the final Bloomie logo, keeping the filename. Add real product photography under `public/images/` and update `data/products.ts` to match.

## Checks

Run `pnpm lint` and `pnpm build` before release. This first version is a business showcase and does not include e-commerce or account features.
